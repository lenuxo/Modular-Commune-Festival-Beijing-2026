1. 上拉进入

首页到底后继续上拉，揭开声音屏幕。

到底露出「继续上拉，玩一点声音」，该文字也能点击进入。建议新增上拉距离 88 CSS px 后进入就绪态，提示「松手开始」；低于阈值松手回弹。入口不发声，预览无触点或播放按钮。

松手 → 待机；未达阈值 → 首页。

2. 待机

首次进入，声音尚未开始。

低亮点阵、无触点、进度熄灭；引导圈只是提示，整个演奏区都可按。首次触摸开始鼓、低音和实时旋律；点「开始」只启动伴奏。无历史乐句时撤销禁用。

首次触摸 → 单指；点击开始 → 伴奏播放。

3. 单指演奏

用一根手指滑出一句。

上下控制音高，左右控制柔亮。菱形触点绑定第一根手指；局部点阵随音高隆起、随声音变化亮度，鼓和低音推动全场起伏。首次演奏撤销禁用；已有历史句时撤销可用。

加第二指 → 双指；全部松开 → 循环。

4. 双指演奏

第二指推动整段音乐。

第二指用空心环标记，以落点为相对原点；上下控制能量，左右控制空间。第二指离开时调制平滑回落，不结束乐句。第一指先离开时剩余手指保留第二指角色，不突然接管旋律；全部松开才成句。

抬第二指 → 单指；全部松开 → 循环。

5. 松手循环

听刚才的一句，或继续试新花样。

移除手指标记，点阵随循环运动，进度逐步点亮。再次按下淡出旧旋律、演奏新句，鼓和低音继续；松手后新句在下一个乐句起点替换，等待期间保留尾音与伴奏。图示已有上一句，因此撤销可用。

再按 → 单指；撤销 → 前一句；停止 → 暂停。

共用行为与补充状态

情况开发参考
停止／恢复停止时所有声部平滑收音、触点清除、点阵变暗、循环进度暂停；保留乐句，按钮变「继续」。继续从乐句起点恢复。停止中触摸演奏区开始新演奏，不删除历史句。
换个感觉弹跳、夜行、漂浮同时切换鼓、低音、音色和速度。待机即时切换，播放时显示所选按钮的小等待点，下一乐句切换；只保留最后一次选择。旋律按音阶级数映射，新旧风格音量保持接近。
撤销只保留前一句。无历史时禁用；有历史时点击，于下个乐句起点恢复前一句，不叠加第二条旋律。首句结束后仍无前一句；第二句完成才可撤销。
静音扬声器按钮静音全部输出，但循环与可视化继续，图标明确划线；首次演奏前若静音，仍保留静音状态。
退出／后台返回手册平滑收音，恢复首页原滚动位置；当前会话保留乐句。切入后台或系统中断立即停止输出与触点，回来保持暂停，由用户点继续。
触摸边界第一、第二指按接触顺序分配角色，不按左右位置分配；额外手指忽略。仅演奏区捕获滑动，底部按钮不录进乐句。触摸取消或系统中断不自动提交新句，保留上一句。
成句以两小节为循环单位，缓存最近完整演奏窗口；短句保留留白，长句取最近窗口。轻微节奏整理与五声音阶约束在内部实现。伴奏起伏和音量有上限，默认始终包含鼓与低频；顶部提示不出现乐理术语。
无障碍与适配触控目标至少44 CSS px，控件避开底部安全区；减少动态模式降低点阵运动和转场，不做闪屏。扫描线不干扰文字。只有演奏区域允许双指玩法，浏览器其余区域保持正常可访问操作；桌面保留点击入口和单指鼠标玩法。

主流程：首页底部 → 上拉就绪 → 待机 → 单指 → 双指 → 松手循环 → 再演奏／停止／返回。
